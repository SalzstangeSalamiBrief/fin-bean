# Budget alert threshold

## Description

A user-configurable budget alert. The user chooses one of two modes: a percentage of salary spent, or a fixed remaining-amount threshold. The alert is shown when the threshold is reached or exceeded.

## Acceptance criteria

- User can configure the alert as either "% of salary spent" or "fixed remaining amount".
- Only one mode is active at a time.
- The alert is shown when the configured threshold is reached/exceeded.
- The configuration is persisted per user.
