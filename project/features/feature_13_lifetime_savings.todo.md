# Lifetime savings

## Description

Each month's remaining budget (salary - expenses) resets at the start of the month and does not roll over into the next month's budget/alert calculation. The surplus/deficit from every completed month is accumulated into a running lifetime total shown to the user.

## Acceptance criteria

- Remaining budget does not roll over into the next month's budget/alert calculation.
- Each completed month's surplus/deficit is added to a running lifetime total.
- The lifetime total is displayed to the user.
