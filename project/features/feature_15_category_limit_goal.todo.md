# Category spending-limit goal

## Description

A goal that sets a maximum spend per category per month, using the same fixed predefined category list as expenses. Actual spending is compared against the limit and progress is shown.

## Acceptance criteria

- User can set a monthly spend limit per category (fixed category list).
- Actual monthly spend per category is compared against the limit.
- Progress / over-limit status is shown to the user.
