# End-of-month report

## Description

An in-app end-of-month report (email delivery deferred to a later version). The report contains the list of expenses with metadata, the remaining budget for the month, and optional spending feedback. Users can browse past months' expenses and reports, not just the current month.

## Acceptance criteria

- Report is available as an in-app view only in v1.0.0.
- Report includes expenses with metadata and remaining budget for the month.
- Report optionally includes spending feedback (when opted in).
- User can browse reports and expenses for past months.
