# Spending Feedback questionnaire

## Description

Users can opt in to "Spending Feedback" in their profile and fill out a questionnaire that builds a "spending profile". The questionnaire and profile storage are implemented in v1.0.0 (the AI analysis is mocked, see the mocked spending feedback feature).

## Acceptance criteria

- User can opt in/out of Spending Feedback in their profile.
- A questionnaire is presented when opted in.
- The resulting spending profile is persisted per user.
- The spending profile can be reviewed/updated by the user.
