# Mocked AI spending feedback

## Description

AI-based analysis of the spending profile against the monthly report is mocked in v1.0.0 (a real locally-hosted AI model is planned for a later version). The mocked output is surfaced in the end-of-month report when the user has opted in.

## Acceptance criteria

- Analysis output is generated by a mock (no real AI model in v1.0.0).
- The mocked feedback appears in the end-of-month report when the user opted in.
- The integration point is designed so a real model can replace the mock later.
