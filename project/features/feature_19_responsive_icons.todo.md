# Responsive design & icon system

## Description

Mobile-first responsive design that works on both desktop and mobile. Icons (lucide) are used throughout the UI. On desktop, icons are paired with text labels plus a hover title/tooltip. On mobile, icons are shown without text labels.

## Acceptance criteria

- Layout is responsive and mobile-first, working on desktop and mobile.
- Icons are used throughout the UI (lucide).
- Desktop: icons paired with text labels and a hover title/tooltip.
- Mobile: icons only, no text labels.
