# Localization (English & German)

## Description

Add internationalization using Paraglide. All UI text is translated into English and German. Formatting of dates, numbers and currency is locale-aware. The active language comes from the user profile setting.

## Acceptance criteria

- Supported languages are English and German.
- Switching language updates all UI text immediately.
- Dates, numbers and currency are formatted according to the selected locale.
- A sensible default/fallback language is used when none is set.
