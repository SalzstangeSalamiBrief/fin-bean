# User profile & settings

## Description

Profile settings page where the single-user account manages preferences. The user selects one currency (used for all amounts: salary, expenses, goals) and their language. Settings are persisted per user in the backend.

## Acceptance criteria

- User can select a single currency; it is persisted and used across the whole app.
- User can select their language (English/German); it is persisted.
- All monetary amounts are displayed in the user's selected currency.
- Accounts are single-user only (no shared/family accounts).
