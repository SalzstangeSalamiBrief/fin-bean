# Salary management

## Description

The user sets a single recurring monthly salary value, editable at any time. The current value is used for ongoing (current/future month) calculations. Already-completed months keep the salary value that was active at that time.

## Acceptance criteria

- User can set and edit a single recurring monthly salary.
- The latest value is used for the current and future months.
- Historical (completed) months retain the salary value active at that time.
- Amount uses the user's selected currency.
