# Expense tracking (CRUD)

## Description

Manual expense entry with fields: amount, date and category. Categories come from a fixed predefined list (not user-editable in v1.0.0): Housing, Groceries, Transport, Utilities, Entertainment, Health, Shopping, Other. Expenses can be edited and deleted after creation.

## Acceptance criteria

- User can create an expense with amount, date and category.
- Category is chosen from the fixed predefined list only.
- User can edit an existing expense.
- User can delete an expense.
- Inputs are validated; amounts use the user's selected currency.
